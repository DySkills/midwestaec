# MidwestAEC | Building Science & High-Performance Envelope Systems

> Practical building science, moisture management, thermal envelopes, and cold-climate MEP for ASHRAE Climate Zones 4 & 5.

---

## 🎯 Mission
MidwestAEC bridges the gap between architectural building science and real-world construction trades across the American Midwest (Missouri, Illinois, Indiana, Ohio, Iowa, Michigan, Wisconsin, Minnesota, Kansas, Nebraska).

We publish rigorous, spec-driven engineering teardowns of:
- **Moisture & Water Entry Barriers:** Below-slab vapor retarders, crawlspace encapsulation, liquid-applied WRBs.
- **Thermal & Air Barriers:** Continuous exterior insulation, mineral wool vs. polyiso, vapor-permeable airtightness.
- **Cold-Climate Mechanicals:** Inverter-driven heat pumps, whole-home dehumidifiers, ERV/HRV airflow balancing.
- **Prefab & Offsite Assemblies:** Structural Insulated Panels (SIPs), Insulated Concrete Forms (ICF), panelized envelopes.

## 🔗 How to Connect to GitHub

1. **Create a new repository on GitHub:**
   - Go to [github.com/new](https://github.com/new).
   - Repository name: `midwest-aec` (or `showme-aec`).
   - Set to **Public** (or **Private**).
   - **Do not** initialize with a README, .gitignore, or license (we already created them locally).
   - Click **Create repository**.

2. **Connect and push your local code:**
   Run these commands in PowerShell inside this directory:

   ```powershell
   git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/midwest-aec.git
   git branch -M main
   git push -u origin main
   ```

3. **Enable Free Hosting on GitHub Pages (Optional):**
   - Go to your repository on GitHub -> **Settings** -> **Pages**.
   - Under **Build and deployment**, set Source to **Deploy from a branch**.
   - Select branch `main` and folder `/ (root)`.
   - Click **Save**. Your site will be live on the web at `https://<YOUR-GITHUB-USERNAME>.github.io/midwest-aec/` in under 60 seconds!
